# ألا بذكر الله... — v1.7 (الإصدار النهائي المُدقَّق)

تطبيق Next.js — تصنيف نصي + محتوى قرآني/حديثي + مسار أزمات + صوت تلاوة حقيقي + مشاركة/تقييم/تبرع (اختبار اهتمام).

هذا الإصدار **يستبدل** المشروع القديم "لحظة سكينة" بالكامل — نفس المحرك والقاعدة، بعد تدقيق أخير وتغيير الاسم والهوية.

## ما تغيّر عن آخر إصدار مُسلَّم (لحظة سكينة v1.6)
- الاسم أصبح "ألا بذكر الله..." في كل مكان (الواجهة، عنوان الصفحة، القاعدة، package.json)
- إصلاح استيراد مكرر كان في الكود (نفس الملف يُستورد باسمين)
- معالجة أخطاء حقيقية: لو فشل الاتصال بالخادم تظهر رسالة واضحة للمستخدم بدل شاشة فارغة صامتة
- زر "سؤال جديد" لبدء محادثة من الصفر دون تحديث الصفحة يدويًا
- أيقونة (favicon) بهوية التطبيق بدل الافتراضية

## التشغيل محليًا
```bash
npm install
npm run dev
```

## استبدال المستودع القديم على GitHub (خطوتان، اختر إحداهما)

**الخيار الأول (الأبسط والموصى به): احذف القديم وأنشئ الجديد بالاسم الجديد**
1. على GitHub، افتح مستودع "sakina-app" القديم → Settings (أسفل الصفحة) → Danger Zone → Delete this repository
2. أنشئ مستودعًا جديدًا باسم مثل `ala-bidhikrillah-app`
3. اتبع خطوات الرفع المعتادة أدناه

**الخيار الثاني: استبدل محتوى نفس المستودع القديم بلا حذفه**
```bash
cd ala-app
git init
git add .
git commit -m "الإصدار النهائي: ألا بذكر الله..."
git branch -M main
git remote add origin <رابط نفس المستودع القديم>
git push -u origin main --force
```
⚠️ `--force` يمسح كل تاريخ المستودع القديم نهائيًا ويستبدله بهذا الكود — لا رجعة بعده.

## رفعه لأول مرة (مستودع جديد)
```bash
cd ala-app
git init
git add .
git commit -m "الإصدار الأول: ألا بذكر الله..."
git branch -M main
git remote add origin <رابط المستودع الجديد>
git push -u origin main
```

## نشره على Vercel
1. إن كان عندكم مشروع Vercel قديم مربوط بـ"sakina-app": احذفوه من Vercel Dashboard → Settings → Delete Project
2. "Add New Project" → اختاروا المستودع الجديد → Vercel يتعرّف على Next.js تلقائيًا
3. اختياري: أضيفوا `ANTHROPIC_API_KEY` في Environment Variables لتفعيل التصنيف الاحتياطي بالذكاء الاصطناعي
4. Deploy

## تذكير مهم قبل المشاركة العامة
- `settings.status` لا يزال `CONTENT_REVIEW_REQUIRED` — راجعوا حديث `ILLNESS_TRIAL` المتبقي `PENDING_REVIEW` (لفظان مدموجان، يحتاج اختيار لفظ واحد دقيق)
- اختبروا مسار الأزمة (`SAFETY_CRISIS`) بأنفسكم بجملة تجريبية قبل أي مشاركة واسعة
- `donation_methods` كلها معطّلة عمدًا — التبرع الآن اختبار اهتمام فقط بلا تحصيل مال (راجع `settings.donation_mode`)
