# إلا بذكر الله — V2

نسخة واجهة محسنة مبنية على قاعدة Sakina V1.6 الموجودة دون إعادة بناء المحتوى الديني.

## ما الجديد
- اسم التطبيق: إلا بذكر الله
- واجهة عربية RTL أكثر هدوءاً واحترافية.
- تصنيف محلي مع threshold 0.75.
- مسار SAFETY_CRISIS له أولوية قبل التصنيفات العادية.
- مطابقة كلمات بحدود الكلمات بدلاً من substring الخام.
- عرض المحتوى VERIFIED فقط.
- مواضيع قابلة للتصفح.
- حفظ المحتوى محلياً في الجلسة الحالية.
- مشاركة/نسخ المحتوى.
- "لحظة اليوم".
- رسالة واضحة بأن AI لا يولد المحتوى الديني.

## مهم
هذه نسخة UX/architecture محسنة، وليست اعتماداً نهائياً للمحتوى الديني. أي إضافة لآيات/أحاديث/أدعية جديدة يجب أن تمر بمراجعة مصادر قبل تفعيلها للمستخدم.
